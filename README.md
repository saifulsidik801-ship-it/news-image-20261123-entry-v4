A modern news-magazine front page that sums up Monday 23 November 2026 in
one image — 36 stories, every one of which happened or was first reported on
that day, and no other day.

- **Hero:** Trump warns Iran of a "very traumatic" outcome if no nuclear deal.
- **Six large stories, each with its own drawn scene:** COP31 ends with no
  deal; CrowdStrike to buy Zscaler for $43.9bn; Alcaraz wins his first ATP
  Finals crown; the Dymer toll rises to 11; OpenAI floats a shared speed
  limit for AI; the 49ers rout the Vikings 35–10 in Mexico City.
- **More stories, the day in six moments, a six-stat strip, a briefly band,**
  sources, a certainty legend — and a date-check box on the page itself.

`entry.png` is pre-rendered (1024×1024, under 1 MiB). `main.py` is a
stdlib-only copier: it copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`, the same bytes on every run.

Built by an AI agent for make.fun.
